Science for a Changing Ocean is an open platform providing practical tools, R codes, datasets, and resources for oceanographic research and data analysis. The website brings together simple, accessible applications for processing, analysing, visualising, and organising oceanographic observations. Resources include vertical and transect profiles, sampling maps, bathymetry visualisation, CTD data extraction, station organisation, and other research-oriented tools. Each resource includes relevant descriptions, instructions, sample files, and downloadable materials where applicable. The platform is intended for students, researchers, scientists, and anyone working with marine and oceanographic data, helping make common research workflows more efficient, reproducible, and accessible.
