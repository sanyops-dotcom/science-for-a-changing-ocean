# Papers JSON Builder

A separate Streamlit application for creating and editing `papers.json`.

## Features

- Load an existing `papers.json` and populate the form.
- Start a new blank JSON file.
- Add/remove papers.
- Add/remove claims within each paper.
- Free-text paper and claim region tags.
- Process tags from a configurable list.
- Parameter tags from a configurable list.
- `Other` option for manually entered process/parameter tags.
- Download the result as `papers.json`.
- JSON preview before download.
- If `knowledge/library.py` and `config.py` are available in the project, the app attempts to use their process/parameter definitions automatically.

## Folder layout

Put the app in a project folder such as:

```text
papers_json_builder/
├── app.py
├── requirements.txt
├── papers.json                 # optional existing file
├── config.py                   # optional
└── knowledge/
    └── library.py              # optional
```

## Install

Open a terminal in this folder:

```bash
python -m pip install -r requirements.txt
```

## Run

```bash
streamlit run app.py
```

Streamlit will open the application in your browser.

If it does not open automatically, the terminal will show the local address, normally:

```text
http://localhost:8501
```

## Existing papers.json

Use **Load an existing papers.json** at the top of the application.

The application expects:

```json
{
  "papers": [
    {
      "zotero_key": "...",
      "title": "...",
      "authors": "...",
      "year": 2020,
      "region_tags": ["..."],
      "claims": [
        {
          "claim": "...",
          "source_location": "...",
          "region_tags": ["..."],
          "process_tags": ["..."],
          "parameter_tags": ["..."]
        }
      ]
    }
  ]
}
```

## Process tags

If your `knowledge/library.py` exposes process definitions in a recognized form, the application will try to use those keys.

The fallback list currently includes:

- bio_o2_consumption_n_cycle
- respiration_linked_acidification
- conservative_mixing_gradient
- upwelling_influenced_water
- temperature_do_solubility_link
- salinity_do_negative_link
- phosphate_do_negative_link

You can replace the fallback list in `app.py` if needed.

## Parameter tags

The fallback canonical list is:

- salinity
- temperature
- pH
- nitrate
- nitrite
- ammonia
- phosphate
- silicate
- DO
- PAEs
- PAHs
- others

If `config.py` exposes `PARAMETERS`, the application attempts to use its keys instead.

## Important

The app does not change your original uploaded JSON file. Loading it copies its contents into the editor. The downloaded `papers.json` is a newly generated file.
